Building a virtual cell: seven principles from cfRNA/cfDNA foundation models

Exai-1 and LEAF-1 were built to detect cancer signal in circulating nucleic acids. The architecture choices underneath them — how they compress, condition, tokenize, and generalize — map directly onto what a virtual cell model needs to do.

What a virtual cell model actually does

Given a cell's baseline expression state and a perturbation (drug, knockout, cytokine), predict what the cell's expression profile becomes after that perturbation. Everything below is about how to build the machine that does this prediction well.

Seven principles, operationalized
01 / 07
Compress the cell into a latent, don't operate on raw counts
Orion / Exai-1 — q(z|x) compresses ~7,349 features into z, dim 32

A real cell profile is ~20,000 gene measurements — noisy, sparse, mostly zeros. You can't perturb or compare cells directly in that space; it's too high-dimensional and too noisy. Train an encoder that compresses each cell's expression vector into a small vector z that captures "what kind of cell state this is." This z is the thing the model actually operates on.

Concretely

Two biologically similar cells — same type, similar activation state — end up with similar z vectors even if their raw gene counts differ due to measurement noise. Distance in z-space becomes a meaningful measure of "how different are these cell states," which raw counts don't give you.

02 / 07
Separate technical noise from biology with a dual encoder
Orion — separate Library Encoder q(ℓ|r), decoded abundance μ = ρ × ℓ

Batch, sequencing depth, and prep platform get their own encoder so they don't contaminate the biological latent. This is architectural batch correction, built in from the start rather than regressed out afterward.

Concretely

Training data from five labs' single-cell experiments: the same cell type looks different in raw counts purely from sequencing depth or reagent batch — not biology. Without separating this out, the model wrongly learns that lab identity is part of cell state, and "T cell, resting" from Lab A ends up in a different part of latent space than the same state from Lab B.

03 / 07
Condition on the perturbation, in-context, not as a bolt-on
Exai-1 — special tokens CD / TOO / AV / BT prepended to the input sequence

Feed a token identifying the perturbation being applied — which drug, which dose — alongside the cell's baseline expression, into the same transformer that processes expression. The model learns how different perturbation tokens shift the latent differently, jointly with learning cell state, rather than in a separate downstream step.

Concretely

Instead of training 500 separate models for 500 drug perturbations, one model conditions on a perturbation token. At inference, you can query perturbation #501 — never seen in training — and get a reasonable answer, because the model learned a general perturbation-response function, not 500 lookup tables.

04 / 07
Treat genes as an unordered set, not a positional sequence
LEAF-1 — fragment pool is position-independent, embed by biology not coordinate

Genes don't have a natural order the way words in a sentence do. Feeding "gene 1, gene 2, gene 3..." in arbitrary column order wastes model capacity learning that order means something when it doesn't.

Concretely

Geneformer-style tokenization ranks genes by expression level and treats the cell as an unordered set of active genes. The model attends to which genes are active and how much, not their position in the input vector — the same fix LEAF-1 applies to cfDNA fragments by ignoring genomic position and embedding by content instead.

05 / 07
Pretrain on cheap unlabeled data before fine-tuning on expensive labels
Exai-1 — denoises masked cfRNA at R² = 0.89 vs. 0.57 for a strong baseline

Before the model sees a single labeled perturbation experiment, pretrain it on a large pile of unperturbed cell profiles: randomly hide some genes, ask it to predict their values from the rest. This teaches normal gene co-expression patterns for free, using the far larger pool of unlabeled data.

Concretely

Only after this masked-reconstruction pretraining does the model get fine-tuned on the smaller, expensive set of labeled perturbation experiments. The R² gap over a naive baseline (0.89 vs. 0.57) is the empirical case for why this stage matters — a learned latent substantially outperforms non-learned imputation before any labeled fine-tuning even happens.

06 / 07
Use the latent to synthetically extend small experiments
Exai-1 — synthetic profiles lift AUC by ~0.10, most in small cohorts (Ovarian, n=48)

Because a well-trained latent space is smooth, you can sample new points near real ones and decode them into synthetic examples — effectively multiplying a small dataset without new wet-lab data.

Concretely

A rare cell type with only 40 perturbation experiments ever run isn't enough to train on directly. Sampling synthetic "cells like this" from the pretrained latent pads out the effective dataset — the same mechanism that lifted the ovarian cancer classifier (n=48) in Exai-1's actual results.

07 / 07
Benchmark on what the model never saw, not what it basically already knows
Exai-1 — few-shot to ovarian & head/neck cancers, zero-shot to osteosarcoma

The real test isn't reconstructing a held-out cell that's basically the same type as ones already seen — it's predicting the response to a perturbation, or in a cell type, with zero examples in training.

Concretely

That's what justifies calling it a general-purpose model rather than an interpolation table. For a virtual cell model, the equivalent test is holding out an entire cell type or perturbation class entirely, then checking whether predicted responses are still directionally sound.

How it composes
raw expression (~20k genes) → gene-set tokenization (04) → dual encoder: biology + batch (02) → latent z (01) → conditioned on perturbation token (03) → predicted post-perturbation state
Training order matters as much as the architecture: pretrain the encoder/decoder on unperturbed profiles with masked reconstruction (05) first — this is where most of the representational quality comes from. Only then fine-tune on labeled perturbation data, using latent-space sampling (06) to extend any cell type or perturbation with too few real examples. Evaluate by holding out an entire perturbation class or cell type, not just held-out cells of a type already seen (07).
